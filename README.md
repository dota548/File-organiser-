# File-organiser-
A lightweight Python tool that automatically sorts files into organised folders based on their file type.
Perfect for cleaning up messy directories and keeping your workspace tidy.
Especially if your lazy.

## Features
-Automatically detects file types
-Creates folders if they don’t exist
-Moves files into categories such as:

Images
Videos
Documents
Code
Audio
Archives

Simple, fast, and easy to customise

## How It Works
Run the Python script, and it will:

1. Scan all files in the directory

2. Create category folders

3. Move each file into the correct folder

4. Print a success message when finished

## Installation
You only need Python 3.x installed.
Then clone the repository
